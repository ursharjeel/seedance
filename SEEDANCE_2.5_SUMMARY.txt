================================================================================
TROUBLESHOOTING
================================================================================

If generation fails:
- Check JWT token is valid (refresh from session)
- Verify model name is exactly "seedance-2.5"
- Ensure width/height are reasonable (1280x720 is safe)
- Check Leonardo account has credits

If you get 401/403:
- JWT token expired (they last ~1 hour)
- Use the get-session endpoint to refresh

If polling times out:
- Videos can take 2-5 minutes to generate
- Increase maxAttempts in polling loop

If no video URL:
- Check generation status is "COMPLETE"
- Look for motionMP4URL in generated_images array
- Some generations might fail - check statusReason field
